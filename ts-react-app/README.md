# TypeScript React 移动端应用

这是一个使用现代技术栈构建的移动端React应用，包含完整的用户认证系统。

## 🚀 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite 5.2
- **状态管理**: React Hooks + localStorage
- **路由管理**: React Router DOM v7
- **UI组件库**: Antd Mobile (移动端UI库)
- **样式预处理**: Sass
- **代码规范**: ESLint + Prettier + Commitlint

## 📁 项目结构

```
src/
├── components/            # 通用组件
│   └── ProtectedRoute.tsx # 路由守卫组件
├── pages/                 # 页面组件
│   ├── Home.tsx           # 主页面
│   ├── Login.tsx          # 登录页
│   ├── UserManagement.tsx # 用户管理
│   └── NotFound.tsx       # 404页面
├── pages_home二级路由/     # 首页的子路由页面
├── routes/                # 路由配置
├── styles/                # 样式文件
└── main.tsx               # 应用入口
```

## 🔐 登录系统功能

### 1. 用户认证状态管理

- **登录**: 支持用户名/密码登录
- **登出**: 清除用户状态
- **自动认证**: 页面刷新后自动检查登录状态
- **路由保护**: 未登录用户自动重定向到登录页

### 2. 登录页面特性

- **响应式设计**: 适配移动端和桌面端
- **表单验证**: 用户名和密码的实时验证
- **密码可见性**: 可切换密码显示/隐藏
- **演示登录**: 快速填充演示账号
- **社交登录**: 支持微信、QQ、微博登录（UI展示）
- **错误处理**: 友好的错误提示
- **加载状态**: 登录过程中的加载指示

### 3. 路由守卫

- **ProtectedRoute组件**: 保护需要登录的页面
- **自动重定向**: 未登录用户自动跳转到登录页
- **登录后跳转**: 登录成功后跳转到原目标页面

## 📱 使用说明

### 1. 登录流程

1. 访问应用首页，自动重定向到登录页
2. 输入用户名和密码
3. 点击"登录"按钮或使用"演示登录"
4. 登录成功后自动跳转到首页

### 2. 演示账号

- **用户名**: `demo`
- **密码**: `123456`

### 3. 功能说明

- **演示登录**: 点击"演示登录"按钮会自动填充用户名和密码
- **密码可见性**: 点击密码框右侧的眼睛图标可以切换密码显示/隐藏
- **表单验证**: 用户名至少3个字符，密码至少6个字符
- **登出功能**: 在首页点击"登出"按钮可以退出登录

## 🎨 样式系统

项目使用Sass预处理器，包含：

- **变量系统**: 颜色、字体、间距等设计变量
- **响应式设计**: 移动端优先的响应式布局
- **主题支持**: 支持深色模式
- **组件样式**: 统一的组件样式规范

## 🔧 自定义配置

### 1. 修改主题颜色

编辑 `src/styles/variables.scss`：

```scss
$primary-color: #3498db;
$primary-dark: #2980b9;
```

### 2. 添加新的页面

在 `src/pages/` 目录下创建新的页面组件，然后在路由配置中添加路由。

### 3. 修改登录逻辑

在 `src/pages/Login.tsx` 中的 `handleLogin` 函数中修改登录逻辑。
