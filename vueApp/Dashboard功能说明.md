# Dashboard 数据统计概览功能

## 功能概述

Dashboard 是一个全新的数据统计概览页面，为系统管理员提供全面的数据统计信息和可视化图表展示。

## 主要特性

### 1. 数据统计卡片
- **用户总数**: 显示系统中注册的用户数量
- **管理员数**: 显示系统管理员数量
- **角色总数**: 显示系统角色数量
- **权限总数**: 显示系统权限数量

### 2. 可视化图表

#### 用户角色分布饼图
- 展示普通用户与管理员的分布比例
- 使用环形饼图，支持悬停显示详细信息
- 动态数据，实时反映系统状态

#### 权限类型分布饼图
- 展示不同权限类型的分布情况
- 包括：系统权限、用户权限、内容权限、管理权限、其他权限
- 使用不同颜色区分，视觉效果丰富

#### 系统状态统计柱状图
- 以柱状图形式展示各项数据的数量对比
- 直观显示用户、管理员、角色、权限的数量关系
- 支持悬停显示具体数值

#### 数据增长趋势折线图
- 展示各项数据的历史增长趋势
- 包含6个月的数据变化
- 多条折线对比，便于分析趋势

### 3. 详细数据表格
- 显示各类数据的详细统计信息
- 包含总数、活跃数、非活跃数、活跃率等指标
- 使用进度条直观显示活跃率
- 支持数据导出功能（开发中）

### 4. 实时数据更新
- 页面加载时自动获取最新数据
- 支持手动刷新数据
- 调用所有相关API接口获取真实数据

## 技术实现

### 前端技术栈
- **Vue 3**: 使用 Composition API
- **TypeScript**: 完整的类型支持
- **Element Plus**: UI组件库
- **ECharts**: 图表库，支持多种图表类型
- **Vue-ECharts**: Vue 3的ECharts封装

### 数据接口
- 用户管理API: `/users/list`
- 管理员API: `/managers/list`
- 角色管理API: `/roles/list`
- 权限管理API: `/permissions/list`

### 响应式设计
- 支持桌面端、平板、手机等不同设备
- 图表自适应容器大小
- 卡片布局响应式调整

## 使用方法

### 访问方式
1. 登录系统后，默认进入Dashboard页面
2. 左侧菜单选择"数据概览"
3. 或直接访问根路径 `/`

### 操作功能
- **查看统计**: 页面自动加载并显示统计数据
- **刷新数据**: 点击图表右上角的"刷新"按钮
- **导出数据**: 点击表格右上角的"导出数据"按钮（功能开发中）

## 权限控制

- 所有已登录用户都可以访问Dashboard
- 数据根据用户角色动态显示
- 支持超级管理员、视频审核员、运营维护员等角色
