# Vue 后台管理系统

## 新功能：用户信息显示和退出登录

### 功能说明

1. **用户信息显示**
   - 登录后，在页面头部右上角显示当前登录用户的用户名
   - 显示用户头像（使用用户名首字母作为头像）
   - 用户名旁边有下拉箭头图标

2. **下拉菜单功能**
   - 点击用户名区域会显示下拉菜单
   - 菜单包含两个选项：
     - 切换账号：退出当前账号并跳转到登录页面
     - 退出登录：退出登录并跳转到登录页面

3. **交互体验**
   - 鼠标悬停时头像区域有背景色变化
   - 下拉箭头有旋转动画效果
   - 操作前会有确认对话框
   - 操作成功后会显示成功提示消息

### 使用方法

1. **登录系统**
   - 访问 `/login` 页面
   - 输入用户名和密码
   - 输入验证码
   - 点击登录按钮

2. **查看用户信息**
   - 登录成功后，在页面头部右上角可以看到用户名
   - 用户名显示为登录时输入的用户名

3. **切换账号**
   - 点击用户名区域
   - 在下拉菜单中选择"切换账号"
   - 确认操作后会自动跳转到登录页面

4. **退出登录**
   - 点击用户名区域
   - 在下拉菜单中选择"退出登录"
   - 确认操作后会自动跳转到登录页面

### 技术实现

- 使用 Vue 3 Composition API
- 使用 Pinia 进行状态管理
- 使用 Element Plus 组件库
- 使用 localStorage 存储用户信息
- 使用 Vue Router 进行路由管理

### 文件修改

1. **HomeView.vue** - 添加了头部用户信息显示和下拉菜单
2. **user.ts** - 更新了用户store，添加了从localStorage初始化用户信息的功能

### 样式特点

- 头部使用渐变背景色
- 用户信息区域有悬停效果
- 下拉菜单有圆角和阴影效果
- 响应式设计，适配不同屏幕尺寸
